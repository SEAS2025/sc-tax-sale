What the engine actually does

A parameterized county adapter plus a daily list scanner. After each promised date it follows up for seven days, then writes one statewide 5-year file.

  1. Registry. counties/sc.json names all 46 counties, Census FIPS, and only the URLs that were verified.
  2. Scan. Each day the engine re-reads official treasurer pages. After a promised ad or list date it keeps that county in a seven-day catch window so a late posting is still seen. Owner names are never stored.
  3. 5-year file. repeat downloads a newly posted list, intersects parcel IDs with a 2020–2022 archive, and writes site/data/repeat.json.
  4. Ingest. Family adapters still collapse a local HTML table, PDF, or spreadsheet when you drop a file in inbox/.

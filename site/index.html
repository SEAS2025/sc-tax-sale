What the engine actually does

A parameterized county adapter, not a scraped statewide database.

  1. Registry. counties/sc.json names all 46 counties, Census FIPS, and only the URLs that were verified.
  2. Lexington. Reads a local CSV with columns tms, owner_location_2025_REALAD, owner_location_2022_list, amount_2025_REALAD, amount_2022_list. Geocodes by TMS section grid. Summaries omit owner names.
  3. Beaufort. Parses treasurer PDF text for PINs and amounts. Drafts a treasurer inquiry from a file you already have.
  4. Everything else. The command says there is no adapter yet. That is the point.
